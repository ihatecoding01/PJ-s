# SANKALP — Features List

- **AI Agreement Drafting**: Converts natural language project chats into structured, milestone-based contracts.
- **Smart Escrow Payments**: Non-custodial on-chain escrow locking funds until deliverables are verified.
- **Milestone Tracking & Timers**: Automated milestone workflows with silence auto-release and late delivery penalties.
- **GitHub Deliverable Verification**: Automated code inspection, commit tracking, and AI-assisted deliverable scoring.
- **3-Arbitrator Dispute Resolution**: Decentralized dispute handling using 3 peer arbitrators and median voting.
- **Soulbound Reputation Badges (ERC-5192)**: Non-transferable on-chain proof of work for milestones, on-time delivery, and integrity.
- **Contract & PDF Export**: Downloadable legal agreement certificates with cryptographic Keccak-256 validation hash.
- **Multi-Currency Escrow**: Escrow deposits in MATIC, USDC, or USDT with live currency conversion previews.
- **One-Click Network Switcher**: Fast switching between Localhost (8545) and Polygon Amoy Testnet (80002).
- **Web3 Wallet Authentication**: Secure Sign-In with Ethereum (SIWE) and MetaMask integration.
